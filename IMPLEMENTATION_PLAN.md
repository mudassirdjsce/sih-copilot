## Phase 2 — Historical detection ✅ COMPLETE
9. **CSVs committed into `/data/raw/`:**
   - `data/raw/sih-2025-ps.csv` — 135 rows
   - `data/raw/sih-2026-ps.csv` — 226 rows

11. Embeddings generated from `title + " " + description` using `Xenova/all-MiniLM-L6-v2` (384-dim).
12. Historical JSON bundled inside extension under `extension/data/` (declared in `web_accessible_resources`); no GitHub hosting needed for personal build.
13. Fetch-and-cache: content.js fetches JSON once per session via `chrome.runtime.getURL()`.
14. Similarity computed in offscreen document via `@huggingface/transformers`; result sent back to content script via Service Worker message.
15. Similarity badges displayed per PS row. **Year filter:** matches from the current SIH year (`CURRENT_YEAR = 2026`) are excluded — only prior years shown — preventing 100% self-match.


## Phase 3 — Team-fit scoring ✅ COMPLETE
16. **"My Team Skills" panel** in the filter sidebar: 7 domain sliders (AI/ML, Web, Mobile/App, Hardware, Blockchain, GIS, Cybersecurity), each 0–10. Saved to `chrome.storage.local` key `sih_skill_matrix`. No default — badges hidden until user saves explicitly.
17. **Scoring engine (pure semantic, no theme/category metadata):**
    - OFFLINE: `scripts/generate-domain-relevance.js` embeds 7 domain prototype texts + all 226 2026 PS (title+description) using `Xenova/all-MiniLM-L6-v2`, computes cosine similarity, writes `data/domain_relevance_2026.json` (90 KB).
    - RUNTIME: content.js fetches the static JSON, builds `Map<normalizedPsId, domainRel>`. Team Fit = `Σ softmax_rel[d] × skill[d]/10 × 100` (temperature T=0.08). Zero model inference at runtime.
    - Lookup uses `normalizePSId(rec.psId)` to bridge portal's `"SIH26001"` format and JSON's `"26001"` format.
18. **Team Fit badge** displayed inline per PS row, color-coded: green (≥70), amber (40–69), muted (<40).
19. **Major-domain tag** (purely informational, `[ML]` / `[GIS]` / etc.):
    - Generated by `scripts/generate-domain-tags.js` using weighted keyword classification on title + description.
    - Stored as `domainTag` field in `domain_relevance_2026.json` (same file, no new pipeline).
    - 120/226 PSs tagged; 106 left untagged where signal is ambiguous.
    - Rendered as a muted `.sih-domain-tag` pill — **never used in scoring, filtering, or sorting**.
