SIH Copilot — Privacy Policy

Effective date: September 2026  ·  Extension version: 1.0.0

Short version: SIH Copilot does not collect, transmit, or share any personal data. Everything you enter (team skills, notes, status tags) stays on your own device. No account is required.

1. What SIH Copilot does

SIH Copilot is a Chrome extension that overlays the official Smart India Hackathon (SIH) problem-statement portal (sih.gov.in) with a personal review workspace. It adds status tagging, persistent notes, advanced filters, historical-repeat detection, and Team Fit scoring to help participants evaluate problem statements efficiently.

2. Data stored locally on your device

The following data is saved in your browser's chrome.storage.local storage. It never leaves your device:

  • PS status tags — your Unread / Revisit / Selected / Rejected label per problem statement.
  • Notes — free-text notes you write for individual problem statements.
  • Team skill matrix — the domain skill ratings (AI/ML, Web, Hardware, etc.) you enter in the "My Team Skills" panel.
  • Historical dataset cache — a cached copy of the bundled historical problem-statement dataset, kept for fast access between browser sessions.

None of this data is uploaded to any server, shared with any third party, or accessible outside your browser.

3. Data read from the SIH portal

The extension reads problem-statement information (title, description, organization, category, theme) directly from the sih.gov.in page you are already viewing. This data is processed locally to display badges and compute scores. It is not stored beyond what is described in section 2, and it is never transmitted to any external server.

4. Network requests made by the extension

The extension makes the following network requests:

  • Historical embeddings & domain relevance data — Fetched from the extension package itself (chrome.runtime.getURL()). These are static, pre-computed JSON files bundled with the extension. No external server is contacted for this data.
  • Sentence-embedding model weights — On first use of the historical-similarity feature, the extension downloads the Xenova/all-MiniLM-L6-v2 model weights from the Hugging Face Hub CDN. After the first download these weights are cached by your browser and no further download occurs. The model runs entirely inside your browser — no text or problem-statement content is sent to Hugging Face.
  • ONNX WebAssembly runtime — The ONNX runtime WASM binary used to run the model is fetched from cdn.jsdelivr.net on first use and cached by the browser thereafter.

In summary: only anonymous, non-identifiable static assets (model weights, a WASM binary) are downloaded from external CDNs. No user data, no problem-statement text, and no skill matrix entries are ever sent to any external server or API.

5. Permissions used and why

  • storage — to save status tags, notes, and skill matrix in chrome.storage.local.
  • tabs — to detect navigation within the SIH portal so the extension can re-initialize when the user navigates between pages.
  • offscreen — to run the sentence-embedding model in an offscreen document (a Manifest V3 mechanism for background computation that cannot run in a service worker).
  • host_permissions: https://www.sih.gov.in/* — to inject the content script and read problem-statement data only on the SIH portal. The extension is not active on any other website.

6. No personal data collected

SIH Copilot does not:

  • Collect your name, email address, or any identifying information.
  • Require an account or login.
  • Track your browsing history or activity outside sih.gov.in.
  • Use analytics, telemetry, or crash-reporting services.
  • Share any data with third parties.

7. Third-party services

The extension's network activity is limited to downloading static files from these services:

  • Hugging Face (huggingface.co, cdn-lfs.huggingface.co) — for the embedding model weights (anonymous CDN download; no data sent).
  • jsDelivr (cdn.jsdelivr.net) — for the ONNX WebAssembly runtime binary (anonymous CDN download; no data sent).

These downloads are one-time (cached after first use) and do not involve any user-generated content.

8. Data retention and deletion

All locally stored data (status tags, notes, skill matrix, cached dataset) can be deleted at any time by removing the extension from Chrome or by clearing Chrome's extension storage. No data exists anywhere else.

9. Changes to this policy

If the extension's data-handling practices change in a future version, this policy will be updated and the effective date revised. The extension version number in the heading above will reflect the version this policy applies to.
